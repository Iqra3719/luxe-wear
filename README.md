# 👗 Luxe Wear PK - E-Commerce QA Automation Portfolio

> Live Demo: **https://luxe-wear-pk.netlify.app** | Tech: Next.js 14, Tailwind, Supabase

A real-world fashion e-commerce website built as a **Test Automation Target** for SDET / QA Automation portfolio.

### 🎯 Why I Built This?
As an SQA Engineer (2Y Exp UK FinTech @Woodex), I needed a real e-commerce site with complex flows (cart, checkout, admin, filters) to showcase my automation skills, instead of dummy sites like SauceDemo.

### ✅ QA Coverage - What I Test On This Site

**1. UI Automation - Playwright + TypeScript**
- `playwright-test` repo contains 50+ test cases
- Product listing, filtering, cart, wishlist
- Admin panel: Add/Edit/Delete product flow
- Cross-browser: Chrome, Firefox, Safari

**2. API Testing - Postman + Newman**
- Supabase REST APIs
- CRUD validation for `/products`
- Auth & error handling

**3. Manual Testing Artifacts**
- Test Plan, Test Cases, Bug Reports
- Tested on Netlify deployment
